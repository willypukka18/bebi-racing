# Bebi Racing

Kart racer arcade 3D dans un rang du Québec complètement exagéré.

**Jouer:** https://willypukka18.github.io/bebi-racing/

Contrôles: W/↑ gaz, S/↓ frein et recul, A D/← → tourner, Espace ou Shift drift (tenir, puis relâcher pour le boost),
E utiliser l'objet (S tenu = derrière, R = lancer devant), Q regarder derrière, H klaxon, C caméra, Échap pause.
Manette: RT/A gaz, LT frein, stick gauche, RB drift, B/X objet, Y regarder derrière.

Ce dépôt contient seulement le jeu compilé.
